# 账号、库存与商品

## 1. 接入账号

1. 进入“账号管理”，选择添加账号/扫码登录。
2. 用目标闲鱼账号在官方客户端完成扫码；若出现人脸或安全验证，按页面提示在官方流程中完成。
3. 等待后台保存登录信息，确认昵称、账号 ID 和运行状态正常。
4. 为账号填写备注，按需开启或暂停账号，并进入编辑页绑定通知渠道。
5. 首次接入后同步一次商品；开始自动化前确认账号处于启用状态。

不要手工向他人发送 Cookie。登录态、指纹和密码等敏感值由系统加密存储，依赖固定的 `XIANYU_DATA_KEY`。

## 2. 创建卡密库存

付款自动发货和评价赠品都先依赖卡密库存。卡密库存分两层：**卡种** 定义"发什么、什么时候发"，**卡密** 是卡种内的具体内容。

先进入“卡密库存”，点击“创建卡种”，只填名称、描述、启用状态和默认延时秒数；保存后复制“卡种 ID”，它是自动化规则和批量铺货表格引用库存的唯一标识。

然后在该卡种一行的操作里点“添加卡密”，选择卡密类型并录入内容：

卡密类型在卡种上选择，决定发货行为：

| 卡密类型 | 适用内容 | 发货行为 |
| --- | --- | --- |
| 批量卡密 | 一次性兑换码、序列号 | 每行一条，按顺序消耗，每条只能用一次。 |
| 固定文本 | 固定说明、链接 | 只取第一条卡密内容，可重复发送、不消耗。 |
| 固定图片 | 固定图片资源 | 只取第一条卡密内容（图片 URL），可重复发送、不消耗。 |

卡密内容一律是文本（固定图片卡种里存的就是图片 URL）。点卡种行里的“管理卡密”进入该卡种的卡密列表，可用其中右上角的“添加卡密”录入内容：

- 分页浏览并选择每页条数；
- 按状态、卡密内容、买家 ID、买家昵称和订单号查询；
- 批量出库（标记已用）、回库（标记可用）、作废与删除；
- 复制单条卡密（弹窗只读，方便复制）。

批量导入（CSV / XLSX）以卡种为基准，一行一条卡密：

| 列 | 说明 |
| --- | --- |
| 卡种 | 卡种名称；相同名称的行会合并到同一个卡种。 |
| 类型 | `card`（批量卡密）/ `text`（固定文本）/ `image`（固定图片）；同一卡种只写一次即可。 |
| 内容 | 卡密内容；批量卡密一行一条。 |
| 描述 / 启用 / 延迟秒 / 多规格 / 规格名 / 规格值 | 仅在该卡种首次创建时生效。 |

卡种不存在时按首行信息创建，已存在时直接追加卡密；类型与内容同时留空的行只用于创建卡种。导入结果会显示每个卡种是新建还是追加、写入多少条卡密，以及失败行的原因。页面右上角“批量导入 → 下载模板”可获取示例文件。

发货时会自动把买家 ID、昵称、订单号、规格和数量写入被发出的卡密条目，因此售出记录可追溯；状态变更不会直接删除卡密。上架前检查库存余量；库存不足时应先补货，不要依赖人工补救。

## 3. 同步或发布商品

进入“商品管理”：

- 对已在闲鱼上存在的商品，选择同步全部或按页同步，确认商品归属到正确账号。
- 对单个新商品，使用发布入口填写标题、描述、价格、库存、邮费和图片。图片必须可用；提交前复核目标账号。
- 批量铺货的默认类目可以留空，也可以通过关键词从闲鱼获取。优先级为逐行类目、页面默认类目、自动识别，最后才使用“电子资料”兜底。
- 批量铺货商品按虚拟商品发布，不依赖实物发货地址；类目兜底不会改变付款后的虚拟交付逻辑。
- 商品发布成功不等于已开启自动发货。仍需在“自动化规则”中按商品/规格绑定卡密组，或在批量铺货表格中一并声明自动化配置。

## 4. 上线前检查

1. 账号在线并已启用。
2. 商品已同步或发布成功，价格、库存和图片正确。
3. 批量铺货的预检明细已显示正确的类目策略。
4. 所需卡密组启用且余量充足。
5. 自动化规则准确匹配商品；有规格时逐个规格确认。
6. 先用测试订单验证，检查订单列表、自动化异常列表和通知记录。
